# Введение

## Зачем эта библиотека

Email Address Kit помогает на границе ввода данных (формы, API, импорт, БД):

- разобрать строку на local-part и domain;
- проверить синтаксис (и опционально DNS);
- безопасно нормализовать;
- понять, один ли это mailbox (`ya.ru` ↔ `yandex.ru`);
- найти совпадения в списке из БД;
- получить ключ уникальности для индекса;
- предложить исправление опечатки в домене (`gmial.com` → `gmail.com`);
- отдельно отметить disposable-домены.

Библиотека **не** отправляет письма, не ходит в SMTP и не проверяет существование mailbox на сервере.

## Принципы

1. **Parse не бросает на «плохом» email** — сначала объект, потом `isValid()`.
2. **Нормализация ≠ исправление** — lowercase без догадок о намерениях пользователя.
3. **Сравнение ≠ нормализация** — `equals()` / `canonical()` могут сводить equivalents и учитывать стратегию.
4. **Disposable ≠ invalid** — временный адрес может быть синтаксически валидным.
5. **Без фреймворков** — чистый PHP, DI через `EmailFactory`.

## Модель

```text
Email
├── Address   (local-part)
└── Domain
```

`Email` — фасад: валидация, typo, сравнение, disposable подключаются через зависимости factory.

## Что входит / не входит

| Входит | Не входит |
|---|---|
| Parse, validate, normalize | SMTP / IMAP / POP3 |
| equals, filterEquals, canonical | Проверка «ящик существует» |
| Typo / correct домена | Отправка писем |
| Справочник провайдеров | Полный reputation/WHOIS |
| Disposable-проверка | Блокировка disposable внутри `isValid()` |
| IDN-домены (с `intl`), EAI local-part | |
